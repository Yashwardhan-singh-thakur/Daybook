# Web Design Guidelines

Use this skill when reviewing user interface code for design, accessibility, and user experience issues.

## Review workflow

1. Read the requested files and the project's `DESIGN.md`.
2. Fetch the current [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) before each review; do not rely on an old local copy.
3. Check the implementation against the current rules and the project's design direction.
4. Report actionable findings with file and line references, ordered by severity. If there are no findings, say so.

## Upstream skill

This project skill follows Vercel's [`web-design-guidelines`](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) skill. Keep its current review behavior and source guidelines in view when updating this file.
